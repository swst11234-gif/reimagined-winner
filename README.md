# MVP витрина цветов (GitHub Pages)

Статический сайт для малого бизнеса: клиент быстро выбирает букет и отправляет заявку в WhatsApp или Telegram без корзины и онлайн-оплаты.

## Структура

```text
/docs
  index.html
  styles.css
  app.js
  /data/products.json
  /assets/*
```

## Как включить GitHub Pages

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В блоке **Build and deployment** выберите:
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/docs`
4. Сохраните. Через 1–2 минуты сайт станет доступен по ссылке из этого же раздела.

## Как редактировать товары

Все товары лежат в файле: `docs/data/products.json`.

Для каждого товара заполните поля:

- `id` — уникальный ID (латиница, без пробелов)
- `title` — название
- `price` — цена числом, без валюты
- `category` — тип (`букет`, `композиция`, `розы`, `сезонное`)
- `tags` — массив меток (например: `"хит"`, `"новинка"`)
- `short` — короткое описание для карточки
- `description` — полное описание
- `composition` — состав
- `size` — размер
- `images` — массив путей до фото (например: `"assets/my-bouquet.jpg"`)
- `availability` — `in_stock` или `preorder`

После изменения `products.json` просто закоммитьте изменения — GitHub Pages обновит сайт автоматически.


## Как обновлять карточки (добавить / удалить / менять раздел и цену)

Карточка = один объект в `docs/data/products.json`.

### 1) Добавить новую карточку
1. Откройте `docs/data/products.json`.
2. Скопируйте любой существующий объект товара целиком.
3. Вставьте его в массив (между `[` и `]`) через запятую.
4. Измените минимум эти поля:
   - `id` (обязательно уникальный, например `rose-35-red`)
   - `title`
   - `price`
   - `category`
   - `short` и `description`
   - `images`
5. Сохраните файл и проверьте JSON на ошибки (см. ниже).

### 2) Удалить старую карточку
1. В `docs/data/products.json` найдите объект товара по `id`.
2. Удалите весь объект `{ ... }`.
3. Проверьте запятые между соседними объектами (частая ошибка JSON).

### 3) Переместить товар в другой раздел
Разделы на сайте строятся из поля `category`.

Чтобы перенести карточку в другой раздел, просто измените значение `category`, например:
- было: `"category": "букет"`
- стало: `"category": "розы"`

Рекомендуемые значения: `букет`, `композиция`, `розы`, `сезонное`.
Если указать новое значение, оно автоматически появится в фильтре "Тип".

### 4) Поменять цену
Измените поле `price` числом без символа валюты:
- корректно: `"price": 3990`
- некорректно: `"price": "3990 ₽"`

Цена в рублях и формат вывода на сайте подставляются автоматически.

### 5) Важный момент про блок «Популярное»
Блок «Популярное» показывает **первые 6 товаров** из `products.json`.

Хотите поменять порядок в «Популярном» — переставьте нужные товары выше в списке JSON.

### 6) Быстрая проверка после правок
В корне проекта выполните:

```bash
python3 -m json.tool docs/data/products.json
```

Если команда отработала без ошибки — JSON валиден.

## Как добавить фото

1. Загрузите изображения в `docs/assets/`.
2. В товаре в `products.json` укажите путь к файлу относительно `docs/`, например:
   - `"assets/rose-19.jpg"`
3. Можно указывать несколько фото в массиве `images`, они покажутся в модальном окне.
4. Рекомендуемый размер для аккуратного вида в модальном окне: **1200×1200 px** (квадрат).

### Если фото не отображается (частые причины)
- Проверьте точное имя файла и регистр букв: `Rose.jpg` и `rose.jpg` — это разные файлы.
- Проверьте расширение: `.jpg`, `.jpeg`, `.png`, `.webp`.
- Проверьте путь в JSON: должен быть относительно `docs/`, например `assets/my-photo.jpg`.
- Если копировали путь из Windows, замените `\` на `/`.
- После обновления на GitHub Pages иногда нужен hard refresh (Ctrl/Cmd + Shift + R), чтобы сбросить кэш.

На сайте включен безопасный fallback: если путь к фото битый, автоматически покажется заглушка.

## Как поменять город, номер, время работы и ссылки на звонок/мессенджеры

Откройте `docs/app.js` и отредактируйте объект `CONFIG` в самом начале файла.

Текущие значения по умолчанию:
- `city: "Астрахань"`
- `phone: "+7 (900) 000-00-00"`
- `workingHours: "Ежедневно, 08:00–21:00"`

Что за что отвечает:
- `city` — город в заголовке сайта.
- `phone` — основной телефон. Используется для отображения и для ссылки **Позвонить** (`tel:` формируется автоматически из `phone`).
- `workingHours` — строка с графиком работы в шапке и инфоблоке.
- `whatsappNumber` — номер для WhatsApp в международном формате, только цифры (пример: `79001234567`). Из него формируется ссылка `https://wa.me/<номер>`.
- `telegramUsernameOrLink` — либо полный URL (например `https://t.me/flowers_astrakhan`), либо username (например `flowers_astrakhan` или `@flowers_astrakhan`).
- `preferredMessenger` — куда ведёт кнопка **Заказать** в модалке: `"whatsapp"` или `"telegram"`.

Остальные настройки:
- `shopName`
- `currency`
- `deliveryInfo`
- `minimumOrder`

## Быстрые маркетинговые блоки на витрине

### Блок «Повод подарить цветы»

В `docs/index.html` есть секция «Повод подарить цветы». Кнопки из этой секции фильтруют карточки каталога по тегам товара.

Чтобы карточка попадала в конкретный повод, добавьте в `docs/data/products.json` соответствующий тег в массив `tags`:

- `день рождения`
- `романтика`
- `праздник`
- `комплимент`
- `без повода`

Пример:

```json
"tags": ["хит", "день рождения", "праздник"]
```

### Конструктор «Собрать микс-букет»

На главной странице есть отдельная кнопка «Собрать микс-букет», которая открывает пошаговый конструктор.

Что можно настраивать в конструкторе:
- количество тюльпанов;
- 1–4 цвета;
- стиль микса;
- тип упаковки.

Визуальные превью стилей хранятся в `docs/assets/mix_examples/`.
Если нужно заменить примеры, достаточно подменить SVG/изображения в этой папке, сохранив имена файлов, которые уже используются в `docs/app.js`.

## Локальный запуск

Можно открыть `docs/index.html` в браузере.

Если браузер блокирует загрузку JSON через `fetch` при открытии файла напрямую (`file://`), запустите локальный сервер в корне проекта:

```bash
python3 -m http.server 8000
```

И откройте `http://localhost:8000/docs/`.



## Как обновить галерею работ

1. Положите фотографии в `docs/images/gallery/`.
2. Откройте `docs/app.js` и обновите массив `GALLERY` (поля `src`, `alt`, `caption`).
3. Для каждого `src` указывайте путь относительно `docs/`, например: `images/gallery/my-work-1.jpg`.

Пример элемента:

```js
{ src: "images/gallery/my-work-1.jpg", alt: "Букет 31 тюльпан, микс, крафт", caption: "31 • микс • крафт" }
```
